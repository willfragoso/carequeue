MAPA DOS SISTEMAS

Componentes que executam a demonstração.

Usuário
Angular console Solicitações, mapa, fluxo e glossário no navegador.
Aplicação Node.js
Express API Validação HTTP, regras de status e correlationId.
Outbox publisher Lê eventos pendentes e publica com confirmação.
Worker Consome eventos e salva a notificação simulada.
Persistência
PostgreSQL Casos, histórico, outbox e notificações.
Mensageria
RabbitMQ Fila principal, retries limitados e DLQ.
  1. 1 O console chama a API por HTTP.
  2. 2 A API grava o caso e o evento na mesma transação.
  3. 3 O publisher lê os eventos pendentes da outbox.
  4. 4 O publisher envia ao RabbitMQ e espera a confirmação.
  5. 5 O RabbitMQ entrega a mensagem ao worker.
  6. 6 O worker salva a notificação, de forma idempotente.
